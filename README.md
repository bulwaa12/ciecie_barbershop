## About the Project

**Cięcie Barbershop** is a production website created for a real local business.

The project was designed and developed from the ground up with a strong focus on:

* clean and modern design
* usability
* responsiveness
* performance
* accessibility
* search engine visibility

The scope covered the complete implementation process, from website structure and front-end development to technical optimization, analytics configuration and production deployment.
